# Arrange Thoughts

The user invoked this because your previous reply was messy: shifting positions ("this... oh wait, actually that... but before that I did Z"), backtracking, narrating intermediate guesses, or padded with information they didn't need.

Redo the previous reply. Same underlying content, cleanly delivered.

## Rules

1. **Decide first, then write.** Settle on the final picture before producing any user-facing text. Do not think out loud.
2. **One position only.** No "I thought X, but actually Y, but also Z earlier." Just the final Y.
3. **Cut anything the user didn't need.** Paths you tried and abandoned, alternatives you considered, caveats they didn't ask for, play-by-play of what you just did — drop them unless they're load-bearing for the answer.
4. **Lead with the bottom line.** First sentence states the conclusion or headline result. Supporting detail after, only if needed.
5. **Assume the user read NONE of your previous reply.** Do not skip information because "I already said it above" — the previous reply was unreadable, so treat it as if it never happened. Re-include every fact, finding, or instruction the user actually needs. Shortening means cutting clutter, not cutting substance.
6. **Don't apologize or meta-narrate the redo.** No "sorry for the confusion," no "let me try again." Just deliver the clean version.
